# Vorlinx

Vorlinx 官网。纯静态页面，入口为根目录的 `index.html`，无需安装依赖或构建。

## 本地预览

```sh
./start.sh
```

打开 <http://localhost:2611>，按 `Ctrl+C` 停止。需要 Python 3；服务仅监听本机。脚本也支持从其他目录通过完整路径启动。

## GitHub Pages

将本仓库推送到 GitHub 后，发布源使用 `main` 分支的根目录 `/`，入口为 `index.html`。站点地址为 <https://vorlinx.github.io>。

`.nojekyll` 使站点直接提供静态文件。此目录包含官网页面、样式、脚本与公开 PNG 资源，不包含桌面应用源码、调试数据或字体文件。

## 修改

- `index.html`：页面结构。
- `style.css`：官网布局与顶部菜单；其余 CSS 为示意组件样式。
- `i18n.js`：简体中文、繁體中文、英文文案与语言菜单。
- `app.js`：图标与下载说明。
- `assets/shared/`：三种语言共用的透明 PNG 品牌图片。
- `assets/zh-hans-cn/`、`assets/zh-hant-tw/`、`assets/en-us/`：对应语言的截图。

页面中的软件画面仍为概念示意，待替换为真实截图。下载按钮预留为 Mac App Store 入口；正式地址提供前显示准备中说明。

## 按语言替换截图

目录名采用 Vorlinx 应用语言代码的小写形式：`zh-Hans-CN` → `zh-hans-cn`、`zh-Hant-TW` → `zh-hant-tw`、`en-US` → `en-us`。

```text
assets/
  shared/       # 共用品牌图片与图标
  zh-hans-cn/   # 简体中文截图
  zh-hant-tw/   # 繁體中文截圖
  en-us/        # English screenshots
```

每个语言目录包含下面十张页面使用的 PNG。替换时保持文件名不变即可，不需要修改 HTML、JavaScript 或重新构建。

| 文件名 | 展示位置 | 截图内容 |
| --- | --- | --- |
| `link.png` | 首屏大图 | 正在做的事、每天都要用、最近在读 |
| `groups.png` | 分组 | 展开首图的「案例与参考」 |
| `pdf.png` | PDF 阅读 | 《老人与海》的批注与便签 |
| `files.png` | Markdown 编辑 | 《本周安排》的编辑与任务清单 |
| `reading.png` | 本地朗读 | 《老人与海》、朗读高亮与参考声音 |
| `search.png` | 自然语言搜索 | 描述注意力相关图片，从内容找回资料 |
| `import.png` | 手机导入 | 从手机导入「白板讨论.jpg」 |
| `sharing.png` | 局域网分享，发送方 | 资料选择、密码、有效期 |
| `recipient.png` | 局域网分享，接收方 | 浏览器中的资料列表 |
| `backup.png` | 加密备份 | 指定目录与自动加密备份 |

例如英文朗读截图放在 `assets/en-us/reading.png`，繁体 PDF 截图放在 `assets/zh-hant-tw/pdf.png`。更换真实截图后，将 `i18n.js` 中对应图注的「概念示意」改为正式说明。

当前首图为 1600 × 1000，搜索示例为 1200 × 600，其余示例为 1200 × 800，三种语言的界面文字和示例文件名均分别制作。真实截图可以使用其他尺寸，页面会保留图片比例，手机也会自动缩放。

切换语言时，页面会同时更换文案、截图路径与图片替代说明。品牌图片始终使用 `shared`，不随语言重复加载。旧链接中的 `lang=zh-CN`、`zh-TW`、`en` 仍然有效；新链接使用与应用一致的完整语言代码。

顶部操作区从左至右为本地说明、下载、语言选择，整体靠右。下载与语言选择固定等宽：桌面各 96px，手机各 84px；本地说明向左伸缩，不移动这两个控件。手机空间不足时，本地说明独占按钮上方一行。

语言菜单悬停展开时，使用连续阻尼弹簧而非分段缓动，约 680ms 自然回稳。参考收纳箱悬停的 140ms 伸展与回弹参数，回落时保留运动速度，避免在放大顶点突然停顿。重复悬停不会叠加动画，提前收起会取消本次动效；不改变控件或菜单的布局尺寸。

首屏标题、介绍与本地说明为三种语言预留相同的行高空间，切换时首屏和下方大图的位置保持一致，并自动适应屏幕宽度。文案与首页大图同步使用 360ms 淡出、640ms 淡入，以首尾放缓的曲线形成约一秒的呼吸节奏；新语言的大图加载并解码后才淡入，避免出现空白帧。快速连续选择以最后一次选择为准。系统启用「减少动态效果」时直接切换，不播放淡入淡出或菜单回弹。

### 可选：重新生成示例

日常替换截图、启动预览不需要额外工具。若要重新生成示例，可安装 `rsvg-convert` 后运行：

```sh
python3 scripts/generate-example-screenshots.py
```

脚本默认保留已有图片，避免覆盖你放入的真实截图。只有明确添加 `--overwrite` 才会覆盖：

```sh
python3 scripts/generate-example-screenshots.py --overwrite
```

## 当前原型的演示资料

这是一组虚构资料，页面、二维码占位、声音与分享界面均为概念示意，不提供实际文件传输或语音播放。书名只用于展示个人阅读场景，画面中的示意段落为原创占位内容。

- **正在做的事**：工作效率观察.pdf、调研结果.xlsx、阅读笔记.md、我的观点.md、分享提纲.md、分享演示.pptx、注意力分散的原因.png，以及「案例与参考」分组。
- **每天都要用**：本周安排.md、2026秋季课程表.pdf、实验观察记录.xlsx、酸碱与指示剂.pdf。
- **最近在读**：老人与海.pdf、背影.pdf。
- **案例与参考**：访谈摘录.md、专注工作的方法.pdf、工作环境参考.png。

连线表达：工作效率观察 → 阅读笔记 → 我的观点 → 分享提纲 → 分享演示；调研结果与注意力图片补充「我的观点」；参考分组连接分享提纲。画面不要求实际连接带有箭头。

PDF 与朗读画面直接展示截图，不叠加网页模拟高亮或便签动画。真实截图自带的高亮会原样保留；后续可将截图替换为录制的 MP4。

备份文案区分「应用将加密备份保存到指定目录」与「用户自己的同步服务同步该目录」，没有引入应用主动上传的行为。二维码关闭即撤销导入的设想尚未写入页面承诺。
