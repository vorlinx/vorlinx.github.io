常見問題

AI 功能需要上傳檔案嗎？

檔案分析、語意索引與朗讀在本地執行。使用 AI 功能前，需要先準備相應模型。

第一次使用，從哪裡開始？

先匯入幾份常用資料，在畫布上連結相關檔案，或按主題建立分組；之後可以直接開啟閱讀、搜尋內容，或新增 Markdown 筆記。

手機和 Windows 電腦也能傳檔案嗎？

可以透過同一區域網路中的 QR Code 或連結向 Vorlinx 匯入檔案。分享資料時，可設定密碼與有效期限，由對方透過瀏覽器存取。

備份可以儲存在哪裡？

備份先加密，再儲存到你指定的目錄。如果該目錄由你使用的同步服務管理，加密備份也可以由該服務同步。

後續計畫：未來版本將逐步支援將加密備份同步至多個雲端儲存服務。

把常用資料留在眼前，讓檔案與思路都有自己的位置。
