Common questions

Do AI features upload my files?

File analysis, semantic indexing and read aloud run locally. Prepare the required models before using AI features.

Where do I start?

Start with a few files you use often. Link related files on the canvas or group them by topic, then open documents, search their content or create a Markdown note.

Can I transfer files from a phone or Windows PC?

Import files through a QR code or link on the same local network. Shared files can have a password and expiry and are accessed in a browser.

Where can I save backups?

Backups are encrypted before being saved to your chosen folder. If you use a sync service for that folder, it can sync the encrypted backup.

Planned: future releases will gradually add support for syncing encrypted backups to multiple cloud storage services.

Keep everyday files in view and give your ideas room to grow.
